# VIC 更新版

## 変更内容
- `Administrator's Pick` の切り替えは8秒のままです。
- 「出逢いの場 －推しを探す旅－」はランダム表示を4件に変更しました。
- PCでは4件を横一列で表示します。
- スマートフォンでは2列×2段で表示します。
- サムネイル、VIC表記、番号、ジャンル、活動名、よみかた・所属、おすすめポイント、動画リンクは維持しています。

## 更新方法
ZIP内のファイルをGitHubへすべて上書きしてください。Apps Scriptの変更は不要です。

## 今回の変更
- 公開ページのフッターに、ファンメイドサイトであり公式ではない旨の注意書きを追加。


## 今回の変更
- トップページの「Community Recommendation」と「Today's Encounter」の表示順を入れ替えました。

## 今回の変更
- トップページの「おすすめを登録する」ボタンを、上品なグラデーション・影・丸型矢印付きの大きなCTAへ変更しました。
- 既存の機能・文言・表示順は変更していません。


## スクロール表示演出
- トップページの各ブロックが、画面に入ると下から静かにフェード表示されます。
- おすすめカードは最大4枚を、ゆっくりした時間差で表示します。
- 画面外へ出た後、再び画面に入るたびに演出します。
- 端末の「視差効果を減らす」設定にも対応しています。
- Apps Scriptの更新は不要です。


- スクロール演出を繰り返し発動に維持
- 演出速度をゆっくりめに調整


- トップページの主要見出しに、スクロールで文字が散って集まる演出を追加
- 既存のゆっくりしたスクロール表示・4件表示・8秒切り替えなどは維持


## 今回の変更
- 「出逢いの場」の検索結果を3件表示へ変更
- 中央1件＋左右2件のメリーゴーランド風3Dカルーセル
- 右のカードが中央へ、中央が左へ回る方向で約4.8秒ごとに自動回転
- マウスオーバー・キーボード操作中は一時停止
- 左右カードを押すと、そのカードが中央へ移動


- 「このジャンルで表示」ボタンを削除（ジャンル変更時に自動更新）
- トップのジャンル一覧へ「歌ってみた」「オリジナルソング」を追加
- 文字が集まる演出と3件メリーゴーランド表示を維持


## 出逢いガチャ動画の操作変更
- 埋め込みプレイヤーの停止・シーク・音量・全画面・キーボード操作を無効化
- ミュート・自動再生・ループを維持
- 動画部分をクリックすると元のYouTube動画を新しいタブで開きます
- Apps Scriptの更新は不要です


## 出逢いガチャ動画の広告操作
- 通常時はプレイヤー操作をロックし、動画クリックでYouTubeを新しいタブで開きます。
- プレビュー下部右側の「広告を操作する」を押すと5秒間だけプレイヤーを操作できます。
- 5秒後は自動で再ロックされます。


- トップページのヒーロー背景に、暖色の光とリングがゆっくり動くCSS演出を追加
- 文字・管理人おすすめ・既存機能には変更なし
- 端末の「視差効果を減らす／モーションを減らす」設定時は自動で停止

- 管理画面「公開VTuber編集」内の「おすすめ動画を編集」へ「歌ってみた」「オリジナルソング」を追加
